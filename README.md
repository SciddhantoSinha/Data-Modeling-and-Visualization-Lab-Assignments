# Data Modeling & Visualization Lab

This repository contains all lab experiments and assignments completed as part of the **Data Modeling & Visualization Lab (Semester VI)**.  
The work focuses on **data preprocessing, visualization, exploratory data analysis, data modeling**, and **dashboard creation** using industry-standard tools.

---

## 🎯 Course Overview

The objective of this lab is to gain **hands-on experience** in:
- Preparing and transforming real-world datasets
- Visualizing data for meaningful insights
- Applying basic statistical and machine learning models
- Creating interactive dashboards using visualization tools

---

## 🛠 Tools & Technologies Used

- **Programming Languages:** Python, R  
- **Visualization Tools:** Tableau, Power BI  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn  
- **Data Sources:** CSV, XML, JSON, SQL, NoSQL  

---

## 🧪 List of Experiments

1. **Data Preprocessing**
   - Data cleaning, handling missing values, and data formatting using Python/R

2. **Data Visualization**
   - Graphs and plots using Python/R libraries

3. **Data Transformation**
   - Feature engineering and data reshaping

4. **Exploratory Data Analysis (EDA)**
   - Statistical summaries and pattern discovery

5. **Data Modeling**
   - Linear Regression  
   - Logistic Regression  
   - K-Nearest Neighbors (KNN)  
   - K-Means Clustering  

6. **Tableau Experiments**
   - Interface exploration
   - Data connection and preparation
   - Aggregations, visualizations, and basic dashboards

7. **Power BI Experiments**
   - Interface exploration
   - Data engineering tasks
   - Dashboards and visual analytics

8. **Multi-Source Data Modeling**
   - CSV, XML, JSON datasets
   - SQL and NoSQL data sources
   - Dashboard creation using Tableau and Power BI
