# Data Modeling & Visualization Lab

This repository contains all lab experiments and assignments completed as part of the **Data Modeling & Visualization Lab (Semester VI)**.  
The work focuses on **data preprocessing, visualization, exploratory data analysis, data modeling**, and **dashboard creation** using industry-standard tools.

---

## 🎯 Course Overview

The objective of this lab is to gain **hands-on experience** in:
- Preparing and transforming real-world datasets
- Visualizing data for meaningful insights
- Applying basic statistical and machine learning models
- Creating interactive dashboards using visualization tools

---

## 🛠 Tools & Technologies Used

- **Programming Languages:** Python, R  
- **Visualization Tools:** Tableau, Power BI  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn  
- **Data Sources:** CSV, XML, JSON, SQL, NoSQL  

---

## 🧪 List of Experiments

1. **Explore data preprocessing operations on a given dataset/data repository using R/Python.**

2. **Explore data visualizations on a given dataset/data repository using R/Python.** 

3. **Explore data transformations on a given dataset/data repository using R/Python.**

4. **Perform Exploratory data analysis using R/Python.**

5. **Explore following data modeling operations on a given dataset/data repository using R/Python**
   - Linear Regression  
   - Logistic Regression  
   - K-Nearest Neighbors (KNN)  
   - K-Means Clustering  

6. **Explore interfaces of Tableau**
   - Explore different tasks for data engineering on a given dataset using Tableau.
   - Connecting to data and preparing data for visualization.

7. **Tableau Experiments**
   - Data Aggregation and Statistical functions
   - Data Visualizations
   - Basic Dashboards

8. **Exploring Interfaces of PowerBI**

9. **PowerBI Experiments**
   - Connecting to data and preparing data for visualization
   - Data Aggregation and Statistical functions
   - Data Visualizations
   - Basic Dashboards  

10. **Download any dataset of CSV files, XML, JSON format and perform data modeling and create a basic dashboard using Tableau and PowerBI**

11. **Download any dataset from SQL and perform data modeling and create a basic dashboard using Tableau and PowerBI**
